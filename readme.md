# Lidar Sphere Tracing Renderer

Start shooting rays by holding ENTER
Move with WASD
Move camera with the arrows

## Compiling

You must have:  
 - SDL2, SDL2_gfx, SDL2_image, OpenMP
 - gcc

### Linux:
To compile run:
```bash
make
```
and to run:
```bash
./main
```

### Windows:
 Install WSL (Windows Subsystem for Linux)
- Folow instructions from: https://learn.microsoft.com/en-us/windows/wsl/install
- When instaled connect VS Code to your WSL (Please use VS Code)
- Then do the same as for linux
